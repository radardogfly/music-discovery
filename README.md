# Resonance

Film-grain music discovery from your own Spotify listening, recommended by Claude.

Single-file frontend on GitHub Pages, one Cloudflare Worker holding the Claude API key, one D1 database remembering what you kept and passed.

- Setup and deployment: `docs/setup.md`
- Frontend reference: `docs/frontend-handoff.md`
- Worker and database reference: `docs/worker-handoff.md`

Photographs from Unsplash. Artist images from Spotify.
